# Posts Reader

A React application built with React, TypeScript, and Vite. It allows users to browse posts and view their details and nested comments.

## Live Demo

https://posts-reader-teal.vercel.app/

## Features

- Browse posts
- View individual post details
- Display nested comments
- Loading skeletons
- Error handling and retry functionality
- Responsive user interface
- Dark and light theme support

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- React Router
- Axios
- JSONPlaceholder API
- Vercel

## Installation

Clone the repository:

```bash
git clone https://github.com/trishamarie13/posts-reader.git
```

Navigate to the project folder:

```bash
cd posts-reader
```

Install dependencies:

```bash
npm install
```

## Environment Variables

Create a `.env` file in the project root and add:

```env
VITE_API_URL=https://jsonplaceholder.typicode.com
```

## Run the Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deployment

This project is deployed using Vercel.

Live website:
